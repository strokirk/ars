# Guideline metadata (`data/guidelines/*.yaml`)

Hand-maintained companion to the generated `data/guidelines.json`. The JSON holds the
**effect rows** (what an effect costs at a given level); these YAML files hold everything
around them that is prose rather than table: the Range / Duration / Target ladders, each
Form's base Individual, the per-Technique-and-Form notes, and the level arithmetic.

`web/src/lib/guidelines.ts` globs this directory at build time (`@rollup/plugin-yaml`
parses it; the app never ships a YAML parser). **To add a supplement, drop in another
`*.yaml` with its own `book:` header — there is no registry and no code to change.**
Entries inherit their file's `book.key` unless they name their own `book`.

Supplements routinely add Ranges, Durations and Targets the core book has not got
(House Merinita's Faerie Magic is the usual example), and sometimes revise a core one.
An entry whose `key` matches a core entry **replaces** it for that book; a new `key`
is added alongside. Every parameter and note is tagged with its book in the UI, and the
Library's book filter can hide anything not in play at your table.

## Schema

Every key is optional; a file supplies only the lists it changes.

```yaml
book:
  key: merinita            # unique, lowercase; used as the tag in the UI
  name: Houses of Hermes — Mystery Cults
  abbr: HoH:MC

ranges:                    # same shape for `durations`
  - key: Road              # the abbreviation used in a spell's R:/D:/T: line
    name: Road
    magnitudes: 2          # integer; what this step adds to the guideline level
    summary: One line, shown in the list.
    description: The full rules prose, shown when the row is expanded.
    ritual: false          # true if the parameter forces the spell to be a Ritual
    notes:                 # restrictions and exceptions, rendered as bullets
      - "Requires the Faerie Magic Virtue."

targets:
  - key: Taste
    name: Taste
    kind: sense            # object | container | sense — the three Target ladders
    magnitudes: 0
    summary: ...
    description: ...
    ritual: false
    base_size: How big the base Target is, when the book says.
    notes: []

forms:                     # per-Form sizing, one entry per Form the book touches
  - name: Animal
    base_individual: A base Individual for Animal is ...
    notes: []

art_notes:                 # the prose above a Technique+Form guideline table
  - technique: Creo
    form: Animal
    notes:
      - "One string per paragraph."
      - "Community Gloss: ..."   # this prefix is styled as an aside, not a rule

level_rules:               # general level arithmetic, shown under the ladder
  - title: Changing Ranges, Durations, and Targets
    text: ...
size_rules:                # target-size arithmetic
  - title: Increasing size
    text: ...

guidelines:                # effect rows — ONLY for a book whose Markdown this repo
  - technique: Muto        # does not carry. Core's come from data/guidelines.json.
    form: Terram
    level: 15              # null (omit) for a General guideline
    effect: ...
    ritual: false
    notes: []
```

## Editing

These files are hand-written and are **not** regenerated by `tools/build.sh` — unlike
`data/guidelines.json`, which is. If you change a guideline *table* in `md/09-spells/`,
rerun `./tools/build.sh`; if you change the prose around it, edit the YAML here.

`cd web && pnpm test` covers the loader: a malformed file, a duplicate `key` within one
book, or a `magnitudes` that is not an integer fails the suite rather than the deploy.
