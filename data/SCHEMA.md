# Rules database (`data/spells.db`)

Queryable SQLite (+FTS5) extract of the Ars Magica reference: **Chapter 9 spells**
and their guideline tables, plus **Chapter 4 Virtues & Flaws** and **Chapter 5
Abilities**. Use plain SQL instead of grepping the Markdown.

- Regenerate after editing the source Markdown: **`./tools/build.sh`**
- Canonical JSON (reviewable / diffable): `data/spells.json`, `data/guidelines.json`,
  `data/virtues_flaws.json`, `data/abilities.json`
- Query: `sqlite3 -header -column data/spells.db "SELECT ..."`

Generated by `tools/extract.py` + `tools/extract_traits.py` (Markdown → JSON) and
`tools/build.py` (JSON → SQLite + FTS5). Spell Technique/Form come from the
`### <Tech> <Form> (Spells|Guidelines)` section headers, **not** filenames.

## Tables

### `spells` (336 rows)

| column | notes |
|---|---|
| `name` | spell title |
| `technique`, `form` | full names, e.g. `Rego`, `Terram` |
| `tech_abbr`, `form_abbr` | `Re`, `Te` |
| `level` | INTEGER, **NULL** for General-level spells |
| `is_general` | 1 if a General-level spell (level NULL) |
| `is_ritual` | 1 if cast as a Ritual |
| `range`, `duration`, `target` | parsed from the `R:/D:/T:` line (e.g. `Voice`, `Mom`, `Ind`) |
| `requisites` | JSON array, e.g. `["Rego"]` (`[]` if none) |
| `damage` | INTEGER `+N damage` from the text, **NULL** if none |
| `design_raw` | the `(Base …)` line verbatim (NULL for General/reference spells) |
| `description` | cleaned plain text (tags/backslashes stripped) |
| `source_file`, `source_line` | provenance into `md/09-spells/` |

### `guidelines` (578 rows)

Per-effect rows from the guideline tables — what an effect costs at a given level
(use for spontaneous magic and "what can I do at level X").

| column | notes |
|---|---|
| `technique`, `form` | |
| `level` | INTEGER, NULL for General guidelines |
| `is_general` | 1 if General |
| `effect` | one effect (multi-effect cells are split into separate rows) |
| `source_file`, `source_line` | |

### `virtues_flaws` (622 rows)

All Virtues and Flaws (from `md/04-virtues-and-flaws/12-general.md`).

| column | notes |
|---|---|
| `name` | |
| `kind` | `Virtue` or `Flaw` |
| `size` | `Minor`, `Major`, `Free`, or `Major or Minor` |
| `category` | primary: `Hermetic`, `General`, `Supernatural`, `Social Status`, `Personality`, `Story`, `Mythic Companion`, `Special` |
| `categories` | JSON array (a few entries list more than one) |
| `tainted` | 1 if a Tainted variant |
| `cost_raw` | the verbatim cost line, e.g. `Minor, Hermetic` |
| `description`, `source_file`, `source_line` | |

### `abilities` (74 rows)

All Abilities (from `md/05-abilities/05-ability-list.md`).

| column | notes |
|---|---|
| `name` | |
| `type` | `General`, `Academic`, `Arcane`, `Martial`, `Supernatural` (NULL for 3 cross-reference stubs) |
| `restricted` | 1 if it needs a Virtue to take (marked `*` in source) |
| `specialties` | comma-separated examples |
| `description`, `source_file`, `source_line` | |

### Full-text search

FTS5 tables, `rowid` joins back to the base table's `id`:
`spells_fts(name, description)`, `guidelines_fts(effect)`,
`virtues_flaws_fts(name, description)`, `abilities_fts(name, description)`.

## Example queries

```sql
-- Rego Terram spells up to level 30 cast at Voice range
SELECT name, level, range FROM spells
WHERE technique='Rego' AND form='Terram' AND level<=30 AND range='Voice'
ORDER BY level;

-- Best damage per level (reliable-at-gauntlet picks): low level, high damage
SELECT name, form, level, damage FROM spells
WHERE damage IS NOT NULL AND level<=25 ORDER BY damage DESC, level;

-- Non-ritual spells I could spont/learn cheaply, by form
SELECT form, count(*) FROM spells WHERE is_ritual=0 AND level<=20 GROUP BY form;

-- Full-text over names + descriptions (FTS5 syntax: AND/OR/NEAR/"phrase")
SELECT s.name, s.technique, s.form, s.level
FROM spells_fts f JOIN spells s ON s.id=f.rowid
WHERE spells_fts MATCH 'sleep OR slumber'
ORDER BY s.level;

-- What can a Creo Ignem caster spont at level <=15?
SELECT level, effect FROM guidelines
WHERE technique='Creo' AND form='Ignem' AND level<=15 ORDER BY level;

-- Search guideline effects by keyword
SELECT g.technique, g.form, g.level, g.effect
FROM guidelines_fts f JOIN guidelines g ON g.id=f.rowid
WHERE guidelines_fts MATCH 'transport OR teleport';

-- All rituals sorted by level (the "unreasonable" high-end)
SELECT name, technique, form, level FROM spells
WHERE is_ritual=1 ORDER BY level DESC;

-- Minor Hermetic Virtues (the powergamer's xp-free multipliers)
SELECT name, size FROM virtues_flaws
WHERE kind='Virtue' AND category='Hermetic' AND size='Minor' ORDER BY name;

-- Virtues whose effect mentions casting or penetration
SELECT v.name, v.size, v.category FROM virtues_flaws_fts f
JOIN virtues_flaws v ON v.id=f.rowid
WHERE virtues_flaws_fts MATCH 'penetration OR "casting total"' AND v.kind='Virtue';

-- Arcane/Academic abilities a magus needs (and whether they need a Virtue)
SELECT name, type, restricted FROM abilities
WHERE type IN ('Arcane','Academic') ORDER BY type, name;
```
